# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 多页拼接海报（POSTER PRESS）

字符画可按真实纸张规格拆分为多页大海报，所有分页均派生自同一份完整字符布局：

- **纸张尺寸**：A4 / A3 / Letter / Legal / Tabloid 及自定义尺寸，支持横向切换。
- **页边距**：决定每页可印范围（纸张尺寸 − 两侧边距）。
- **拼接重叠**：按整字符列/行取整，相邻页重复同一批字符；重叠带内容取自主网格同一坐标，按页序裁切线拼贴可精确还原原图，任何字符都不会被页缝切成两半。
- **裁切标记**：在边距区绘制裁切线、页序标签（第 N / M 页）与拼接方向箭头；屏幕另可显示重叠辅助线（不会进入打印文件）。
- **两种约束模式**：
  - 固定字号：页数随字号、纸张可印范围和字符网格自然增长；
  - 固定海报尺寸：二分反推最大可用字号，成品不超过目标尺寸，并报告实际偏差（只会等比偏小，不裁切内容）。
- **末页比例**：末页不满一页时不拉伸、不补格，成品尺寸始终等于完整网格的物理尺寸。
- **失效规则**：裁剪、字符密度、字符集等任何改变字符布局的操作都会使旧分页失效，重新生成前禁止预览与导出。
- **取消语义**：导出逐页渲染、可随时取消；取消或失败时不会产出任何缺页文件，临时资源全部释放。
- **彩色 / 单色**：仅改变墨色，完全不参与分页计算，字符占位与分页边界在两种模式下逐格一致；另支持白底省墨。
- **下载**：200 DPI 多页 PDF（零依赖内置编码器）或逐页 PNG 的 ZIP 包（含 CRC32 校验）。

### 设计约束

分页计算（`src/features/poster/lib/pagination.ts`）与页面渲染（`src/features/poster/lib/render.ts`）共用同一套字符格宽与行高常量（`papers.ts` 中的 `CELL_EM` / `LINE_EM`），保证"计算得出的页容量"与"实际绘制的字符位置"严格一致。
